# 🍫 Chocolate Sales Performance Dashboard

## 🚀 Project Overview
This project presents an interactive **Sales Performance Dashboard** designed to analyze revenue, shipments, costs, and profitability metrics for a chocolate business.

The dashboard provides a comprehensive view of sales trends, operational efficiency, and salesperson performance, enabling data-driven decision-making.

---

## 📊 Business Objectives
- Monitor overall sales & profit performance
- Track shipment efficiency
- Analyze cost vs revenue dynamics
- Evaluate salesperson contribution
- Measure profitability trends

---

## 📈 Key Metrics Tracked
✔ **Total Sales** – $34M  
✔ **Total Boxes Sold** – 2M  
✔ **Total Shipments** – 6K  
✔ **Total Cost** – $14M  
✔ **Total Profit** – $21M  
✔ **Profit Percentage** – 60.3%
